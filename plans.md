(work laptop, personal laptop, phone).

## How to use

- Add a new section below for each plan or note.
- Edit from any device: GitHub web, the github.dev editor (press `.` in the repo),
  or the GitHub mobile app.
- Avoid storing real secrets (passwords, API keys) here — use a password manager.
